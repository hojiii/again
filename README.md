# 또 왔어?

열 때마다 뚱냥이가 한마디 하는 미니앱이에요. 기능은 그게 전부예요.

자주 열수록 시큰둥해져요. 하루에 처음 열면 반겨주고, 네 번째쯤부터 지겨워하고,
열여섯 번을 넘기면 드러누워서 말을 안 해요. 닫자마자 다시 열면 "방금 나갔잖아"라고 하고,
일주일 만에 오면 "누구세요?"라고 해요.

들은 말은 도감에 쌓여요. 어떤 상황에서 나오는지 힌트만 보여주고 내용은 가려둬서,
남은 칸을 채우려면 그 상황을 만들어야 해요.

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm test        # 대사 선택 규칙 테스트
npm run build   # 번들 빌드 (.ait)
```

`.env`에 광고 그룹 ID와 인앱 상품 productId를 넣어야 광고와 결제가 켜져요.
`.env.example`을 참고하세요. 값이 비어 있으면 광고와 구매 버튼이 자동으로 숨겨져요.
